# Pairs Trading Crypto

Автоматический анализ парного трейдинга для криптовалютного рынка.

## Тикеры (14)

ADA, ICP, ETH, DOT, LINK, ZRO, AAVE, BTC, ATOM, NEAR, XCH, BNB, HBAR, TRX

## Параметры стратегии

| Параметр | Значение |
|---|---|
| Налог | 0% |
| Лот | $200 (дробное количество) |
| Мин. ордер | $10 (требование биржи) |
| Комиссия | 0.4% туда-обратно |
| Плечо | 1x |
| Фильтр ТОПа | Экстремумы >= 30 (5 лет -> 3 года) |
| Торговля | Z ±5% от level |
| Исключение | 3 года < 30 |
| Периоды | 5 / 3 / 1 год |

**ZRO** (листинг 2024) — 5-летний период пропускается (мало данных).

## Расписание

Каждый час 24/7 (cron `0 * * * *`).

## Файлы

- `fetch_crypto.py` — загрузка цен (HTX + Bybit)
- `z_analytics_crypto.py` — ZigZag-аналитика
- `pairs_analysis_crypto.py` — стратегия + сигналы
- `state.json` — состояние
- `cache/*.csv` — кэш цен (date,close)
